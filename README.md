# Student Performance Exploratory Data Analysis (EDA)

## 1. Project Title

**Exploratory Data Analysis on Student Performance Using Python**

This project focuses on analyzing student performance data using Python and Pandas. It includes exploring the dataset, checking missing values and duplicate records, generating statistical summaries, creating visualizations, and identifying patterns, trends, and potential outliers.

## 2. Dataset Description

The `studentsmat.csv` dataset contains information about student demographics, family backgrounds, study habits, and academic performance.

* **Dataset Name:** `studentsmat.csv`
* **Total Records:** 395 students
* **Total Columns:** 33
* **Demographic Information:** School, gender, age, and address.
* **Family Background:** Parents' education, parents' occupations, and family size.
* **Study Habits:** Study time, travel time, and previous class failures.
* **School Attendance:** Number of absences.
* **Academic Performance:** First-period grade (`G1`), second-period grade (`G2`), and final grade (`G3`).
* **Additional Factors:** School support, family support, extracurricular activities, and internet access.

## 3. Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Google Colab
* GitHub

## 4. Setup Instructions

1. Download or clone this repository to your computer.
2. Open the `student_performance_eda.ipynb` notebook in Google Colab.
3. Download the student performance dataset (`studentsmat.csv`).
4. Upload `studentsmat.csv` when prompted by the notebook.
5. Run all the code cells in order.
6. Review the statistical summaries, visualizations, and EDA results.
7. Analyze the patterns, trends, and potential outliers identified in the dataset.
